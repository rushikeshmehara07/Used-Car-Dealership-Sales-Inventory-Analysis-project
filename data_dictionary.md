# Data Dictionary

Source file: `data/used_car_marketplace_top5_dataset.csv`

- Rows: 1,500
- Columns: 17
- Brand values: Hyundai, Mahindra, Maruti Suzuki, Tata, Toyota
- Fuel types: CNG, Diesel, Petrol
- Transmission values: Automatic, Manual
- Cities represented: 10

| Column | Description |
|---|---|
| `Car_ID` | Unique vehicle/listing identifier. |
| `Brand` | Vehicle brand as recorded in the source data. |
| `Model` | Vehicle model. |
| `Manufacturing_Year` | Manufacturing year. |
| `Fuel_Type` | Fuel category. |
| `Transmission` | Transmission category. |
| `KM_Driven` | Distance driven in kilometres. |
| `Owner_Type` | Previous-owner category. |
| `City` | Listing city. |
| `Listed_Price_INR` | Listed price in Indian rupees. |
| `Purchase_Price_INR` | Purchase price in Indian rupees. |
| `Selling_Price_INR` | Selling price in Indian rupees, where available. |
| `Status` | Listing status. |
| `Listing_Date` | Date the vehicle was listed. |
| `Sold_Date` | Sale date, where available. |
| `Car_Age_Years` | Vehicle age in years. |
| `Profit_INR` | Profit in Indian rupees, where available. |
